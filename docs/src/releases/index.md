# Release notes

What each release means for you, newest first. The [changelog](../project/changelog.md) is the
complete record of every change; these pages are the story of each release — its highlights, what
is new, changed and fixed, what does not work yet, and what to do when you upgrade.

Features are frozen until 1.0: the 0.1.x releases take fixes, documentation, and the work toward
1.0's [stability promise](../project/stability.md).

- **[0.1.3](v0.1.3.md)** — architecture decisions are accepted or rejected from the CLI and the
  Review page; every release carries notes.
- **[0.1.2](v0.1.2.md)** — features frozen until 1.0; the stability policy; boards safe to share
  across versions; the VS Code extension ships with every release.
- **[0.1.1](v0.1.1.md)** — the container image names its build and carries the skill.
- **[0.1.0](v0.1.0.md)** — the first public release.
