# kanbanr 0.2.1 — fixes after 0.2.0

*Released 21 October 2026.*

Two fixes found after 0.2.0 shipped, and a library published beside it.

## What's fixed

- **A diagram opened from the book draws in its theme again.** Clicking a diagram in the book opens
  it full size in a new tab. Since diagrams moved to Pele in 0.2.0, that copy drew every shape as
  a black box and lost its labels, on a white page whatever theme you read in. It now keeps the
  diagram's colours and takes the page's background and text colour from the theme.
- **The release's install check reads the monitor correctly.** After publishing 0.2.0, the release
  workflow's check that a fresh install serves its monitor failed on Debian, Ubuntu and Windows.
  The release itself was fine; the check looked for the monitor's script by its old path. It now
  accepts both forms.

## Also in this release

- **`mermaid-lint` is on crates.io.** The diagram check kanbanr runs on every write is published
  as a standalone Rust library with no dependencies: it finds the Mermaid diagrams in Markdown and
  reports each mistake Pele or Mermaid would reject, with its line and rule. The release workflow
  now publishes it beside `ears-classifier`.

## Upgrade notes

Update with `kanbanr self-update` (macOS, Linux) or by rerunning the installer (Windows). Boards
need nothing: 0.2.1 reads the schema-5 boards 0.2.0 migrated. If you are coming from 0.1.x, see
[0.2.0](v0.2.0.md) and run `kanbanr migrate` once per board.
