# kanbanr 0.1.2 — features frozen until 1.0

*Released 2 October 2026.*

From this release, kanbanr's feature set is frozen until 1.0. The 0.1.x releases take fixes,
documentation, and the work that makes the 1.0 promise checkable. This one writes that promise
down, makes boards safe to share across versions, and ships the VS Code extension.

## Highlights

- **What 1.0 keeps compatible is written down.** [Stability](../project/stability.md) lists what
  stays stable from 1.0 until 2.0 — the board format and `config.yaml`, the `.kanbanr` marker, CLI
  commands, flags, exit status and `--json`, the monitor's `/api/…`, the commit trailer and hooks —
  what is not covered, and how anything stable is deprecated before it is removed.
- **An older kanbanr no longer deletes what a newer one wrote.** Rewriting an item, a milestone, the
  config or the charter used to drop every field the running version did not know. Unknown fields
  are now kept and written back unchanged, so machines sharing a board can run different versions.
- **The VS Code extension ships with every release** as `kanbanr-vscode-<version>.vsix`, at the
  program's version and covered by `SHA256SUMS`.

## What's new

- **The release installs itself on every platform it publishes for.** After publishing, it runs
  `install.sh` on macOS and `install.ps1` on Windows (as `irm … | iex`, the way the docs say)
  beside the two Linux containers.

## What's fixed

- **The VS Code extension packages.** It now names the repository and the docs site, carries its
  licence, and installs from the packaged `.vsix` in a clean VS Code.

## Known limits

- The new installer check reported all four platforms as failed for this release, although every
  install worked and named 0.1.2 and its commit: the check ran `kanbanr init` inside the repository
  checkout. Fixed in [0.1.3](v0.1.3.md).
- The extension is not on Open VSX or the Visual Studio Marketplace yet.

## Installing the extension

```bash
gh release download v0.1.2 -R startr-trade/kanbanr -p 'kanbanr-vscode-*.vsix'
code --install-extension kanbanr-vscode-0.1.2.vsix
```
