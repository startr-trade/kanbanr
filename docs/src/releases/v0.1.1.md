# kanbanr 0.1.1 — the container image is the released program

*Released 2 October 2026.*

A fix release for the container image. The binaries and installers are unchanged in behaviour from
[0.1.0](v0.1.0.md); the image now carries exactly the program the archives do.

## What's fixed

- **The image's kanbanr names its build.** `kanbanr --version` in
  `ghcr.io/startr-trade/kanbanr` printed `(unknown, built unknown)`, because the image is built
  without `.git`. It now names the commit and date, like the archives — and the release refuses to
  push an image that cannot.
- **The image's kanbanr carries the skill.** Its binary embedded no Claude Code skill, so it was not
  quite the program the archives ship under the same version. It does now, and the release checks
  the image installs the repository's skill, file for file, before pushing it.

## Upgrade notes

Nothing to do for the binary. If you run the monitor from the image, pull `v0.1.1` (or `latest`).

```bash
docker pull ghcr.io/startr-trade/kanbanr:v0.1.1
```
